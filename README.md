# Raj Singh — 3D Portfolio

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload every file in this folder, preserving the folder structure.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save. GitHub will provide your public portfolio URL.

## How only YOU add work
This portfolio has no public upload or admin form. Visitors can only view your work.

To add or change projects:
1. Open `projects.js` in your GitHub repository.
2. Edit the `projects` or `work` lists.
3. Commit the change.
4. GitHub Pages publishes the update automatically.

Only GitHub accounts with **write access to your repository** can make permanent changes.

Important: A static GitHub Pages website cannot securely contain a private password-based admin dashboard by itself. If you later want a true login dashboard with browser-based uploads, you will need a backend or CMS with authentication.

## Before publishing
- Replace the contact placeholders in `index.html`.
- Replace the placeholder project and video entries in `projects.js`.
- Add optional video thumbnails under `assets/thumbnails/`.
